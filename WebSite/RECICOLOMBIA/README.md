## 🧩 Descripción del Proyecto

Este repositorio contiene el desarrollo completo del **sitio web institucional de RECICOLOMBIA**, una organización dedicada a la sostenibilidad, el reciclaje y la gestión responsable de residuos.

El proyecto se compone de dos partes principales:

1. **Página Institucional (index.html)**  
   Construida en HTML, CSS y JavaScript puro. Contiene toda la información institucional, normatividad, reportes, tarifas y secciones principales del sitio.

2. **Sección Comercial (comercial.php)**  
   Archivo independiente desarrollado en PHP para alojar información y funcionalidades específicas del área comercial, funcionando como una pestaña separada.

El sitio fue desarrollado con tecnologías nativas, optimización para alto rendimiento, compatibilidad en múltiples dispositivos y animaciones visuales personalizadas.

---

## ⚙️ Funcionalidades Implementadas

### 🏠 Página Principal (index.html)
- Sección institucional con información general
- Tarjetas animadas para documentos y normatividad
- Reporte de sostenibilidad con gráficos y métricas por material (plástico, papel, metal, vidrio)
- Sección de tarifas y servicios
- Diseño responsive adaptable a todas las pantallas
- Animaciones de scroll personalizadas por sección
- Optimización SEO y buenas prácticas WCAG AA

### 💼 Sección Comercial (comercial.php)
- Página separada para información del área comercial
- Integración con el diseño visual del sitio principal
- Estructura escalable para agregar catálogos, tarifas o módulos adicionales
